## 📖 Инструкция по применению (Как rawr'ить)

Хочешь Rawr или Mrrreow? Следуй ритуалу:

1.  **Громкий призыв**
    > Rawrrwarwarwarwa
    *(Это значит: "Эй, я здесь!")*

2.  **Нежное бормотание**
    > Mrrremrmwmoewomwemo
    *(Перевод: "У меня есть для тебя rawr")*

3.  **Финальный аккорд**
    > Rowarromwmrowormrmemromemowomrewowrwrrwarwr
    *(Это сакральная фраза, запускающая основную функцию бота. Произносить с чувством!)*
